# Universe FinancialRank

六大財務指標 Rank 台股基本面研究桌面工具，提供排名、個股研究、星系關聯圖、3D 排名熱力圖、資料品質與官方資料匯入流程。

## 原生版本

- macOS Apple Silicon：正式 Developer ID 簽章、公證與 DMG
- Windows 64-bit：Authenticode SHA-256 簽章與單一 EXE

原生發行工作由 `.github/workflows/build-native.yml` 執行。簽章憑證只存於 GitHub Actions Secrets，不進入原始碼或 Git 歷史。詳細設定請見 `NATIVE_BUILD.md`。

## 研究聲明

本工具提供研究資料整理，不提供交易訊號；示範資料不得視為正式投資建議。
