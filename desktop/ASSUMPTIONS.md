# 假設與保守預設

- 單機桌面版以 SQLite 為正式本機儲存；多人協作才升級 PostgreSQL。
- Bronze OpenAPI 回傳只能視為原始來源。未完成季度 taxonomy、單季化與資料品質驗證前，只輸出 `PARTIAL` Silver 包。
- 只有四位數數字代號預設納入普通股候選母體；ETF、權證等非四位普通股格式先排除，正式母體仍須以證券種類欄再次核驗。
- 產業代碼 17 暫映射金融模型；名稱含證券／期貨暫映射證券模型。這項映射只供 PARTIAL 包，不能直接發布 FINAL。
- 缺值、零基期、零平均存貨不補零。
- 同一快照日期、狀態、規則、來源 cutoff 與評分 checksum 完全相同時視為冪等重跑。
